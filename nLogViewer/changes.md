# Список изменений:
## Версия 1.7.1:
    - Копирование записей логов с помощью контекстного меню и Ctrl+C
    - Реализована система индикации прогресса загрузки больших файлов
        - создано модальное окно прогресса с индикатором выполнения
        - реализован ProgressReporter для отслеживания прогресса по байтам файла
        - добавлена поддержка отмены загрузки через CancellationToken
        - интегрирован прогресс в FileLogReader для отчета каждые 100 записей
        - настроена корректная логика закрытия окна при переходе LogViewer в состояние ReadNewMsg
        - установлен порог 10МБ для активации прогресса
    - Реализована виртуализация списка для больших объёмов данных
        - добавлена VirtualizingLogCollection с постраничной загрузкой
        - реализован CircularBuffer для ограничения памяти
        - создана MemoryConfiguration для настройки памяти
        - обновлены LogViewer и LogViewerViewModel для поддержки виртуализации
        - добавлена поддержка кольцевого буфера в LogViewer
    - реализован паттерн Repository для абстракции источников логов
        - создан ILogRepository для унификации доступа к различным источникам данных
        - реализован FileLogRepository для работы с файловыми логами
        - добавлен CompositeLogRepository для одновременной работы с несколькими источниками
        - создан адаптер RepositoryLogSource для обратной совместимости с ILogSource
        - внедрена фабрика LogRepositoryFactory для создания репозиториев разных типов
    - устранено дублирование кода в свойствах фильтра
        - создан базовый класс FilterBase с общей логикой управления свойствами
        - LogEntryFilter переписан с использованием базового класса (100→40 строк)
        - добавлен метод SetProxied в BaseViewModel для упрощения проксирования
        - упрощены свойства фильтра в MainWindowViewModel (11→4 строки на свойство)
    - разделены интерфейсы ILogReader и ILogSource согласно ISP
        - создан интерфейс ILogSource для источников с возможностью модификации
        - методы Clear() и ClearAsync() перенесены из ILogReader в ILogSource
        - обновлены все реализации и зависимости
        - ILogReader теперь отвечает только за чтение данных
    - добавлена комплексная обработка ошибок с агрегированной отчетностью
        - реализована детальная обработка ошибок для каждой записи при пакетном чтении
        - добавлена агрегация ошибок через AggregateException
        - внедрен счетчик ошибок с периодической отчетностью (каждые 5 минут или 100 ошибок)
        - обеспечена устойчивость работы при ошибках в отдельных записях
    - исправлены утечки памяти и ObjectDisposedException при освобождении ресурсов
        - добавлен IDisposable в интерфейс ILogReader
        - реализован паттерн Dispose в FileLogReader
        - исправлен порядок освобождения ресурсов в LogViewer
        - добавлены проверки на disposed состояние для предотвращения ObjectDisposedException
        - добавлена отписка от всех событий в LogViewerViewModel
        - добавлен Dispose для _reader в тестах
    - реализованы асинхронные операции с файлами:
        - добавлены асинхронные методы в интерфейс ILogReader
        - реализовано асинхронное чтение файлов с IAsyncEnumerable
        - обновлен LogViewer для использования асинхронных методов
        - добавлена обработка ошибок и поддержка отмены операций
    - удаление ридера при закрытии просмоторщика
