## 1. Подготовка к тестированию

### Требования
- [ ] Windows машина (WPF приложение)
- [ ] Visual Studio 2022 или VS Code с .NET SDK
- [ ] Task Manager или Performance Monitor
- [ ] Минимум 4 GB свободной RAM
- [ ] Минимум 2 GB свободного места на диске

### Инструменты мониторинга

**Windows Task Manager:**
1. Открыть Task Manager (Ctrl + Shift + Esc)
2. Вкладка "Details" → найти `nLogViewer.exe`
3. Добавить колонки (правый клик на заголовок):
   - Memory (Private Working Set)
   - CPU
   - Threads

**Performance Monitor (опционально):**
```bash
# Запустить Performance Monitor
perfmon
```
